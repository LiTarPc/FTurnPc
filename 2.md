## 4. Фаза 1. Модель данных и парсер ссылок

### 4.1 Расширение `ProfileData`

Профили лежат в `%AppData%\fturnpc\profiles\<name>.json`. Добавляем поле движка и блок sing-box,
сохраняя полную обратную совместимость: пустой `engine` = старый FreeTurn-профиль.

```go
// backend/orchestrator.go
const (
	EngineFreeturn = "freeturn"
	EngineSingbox  = "singbox"
)

type ProfileData struct {
	Name string `json:"name"`

	// "" | "freeturn" | "singbox"; пустое значение = freeturn (старые профили)
	Engine string `json:"engine,omitempty"`

	// --- FreeTurn (как было) ---
	Provider       string `json:"provider"`
	PeerAddr       string `json:"peer"`
	Transport      string `json:"transport"`
	Obf            string `json:"obf"`
	Key            string `json:"key"`
	Cid            string `json:"cid"`
	WGConfig       string `json:"wg"`
	Links          string `json:"links,omitempty"`
	Power          int    `json:"power,omitempty"`
	StreamsPerCred int    `json:"streamsPerCred,omitempty"`

	// --- sing-box ---
	Link     string          `json:"link,omitempty"`     // исходный vless://… (для «показать ссылку»)
	Outbound json.RawMessage `json:"outbound,omitempty"` // готовый outbound-объект sing-box
	Sing     SingOptions     `json:"sing,omitempty"`     // параметры туннеля
}

// SingOptions — то, что пользователь может менять в настройках профиля.
type SingOptions struct {
	Stack       string `json:"stack,omitempty"`        // system | gvisor | mixed (по умолчанию mixed)
	MTU         int    `json:"mtu,omitempty"`          // 0 → 1400
	StrictRoute *bool  `json:"strictRoute,omitempty"`  // nil → true
	Sniff       *bool  `json:"sniff,omitempty"`        // nil → true
	BypassRu    bool   `json:"bypassRu,omitempty"`     // обход RU по geoip-ru.srs
	BypassLAN   *bool  `json:"bypassLan,omitempty"`    // nil → true
	DNSRemote   string `json:"dnsRemote,omitempty"`    // "" → 1.1.1.1 через прокси
	DNSLocal    string `json:"dnsLocal,omitempty"`     // "" → системный (type: local)
	IPv6        bool   `json:"ipv6,omitempty"`         // выключен по умолчанию
	ClashPort   int    `json:"clashPort,omitempty"`    // 0 → 9095, для пингов/статистики
}

func (p *ProfileData) EngineKind() string {
	if p.Engine == EngineSingbox {
		return EngineSingbox
	}
	return EngineFreeturn
}
```

`ConnectParams` менять почти не нужно — `MTU`/`BypassRu` уже есть; добавляем только явный `Engine`
(на случай, когда UI хочет переопределить) — но лучше брать движок из профиля, чтобы UI не мог
рассинхронизироваться.

### 4.2 Один парсер ссылок — в Go, а не в TS

Сейчас разбор `freeturn://` живёт во фронте (`wdttLink.ts`), и это нормально для одного простого
формата. Для VLESS/VMess/Trojan/SS парсеров нужно много, и они должны выдавать **точно тот JSON,
который потом уйдёт в конфиг**. Дублировать это в TypeScript и Go — гарантированный источник
расхождений. Поэтому: **парсер один, на Go**, а фронт вызывает его через Wails-биндинг.

```go
// backend/link_parse.go
package backend

import (
	"encoding/base64"
	"encoding/json"
	"errors"
	"fmt"
	"net/url"
	"strconv"
	"strings"
)

// LinkPreview — то, что уходит во фронт для показа в модалке добавления сервера.
type LinkPreview struct {
	Engine   string          `json:"engine"`   // freeturn | singbox
	Name     string          `json:"name"`     // из #fragment или "Server"
	Protocol string          `json:"protocol"` // vless | trojan | vmess | shadowsocks
	Server   string          `json:"server"`
	Port     int             `json:"port"`
	Security string          `json:"security"` // none | tls | reality
	Network  string          `json:"network"`  // tcp | ws | grpc | http | httpupgrade
	Outbound json.RawMessage `json:"outbound"` // готовый outbound sing-box
	Raw      string          `json:"raw"`      // исходная ссылка
}

// ParseProxyLink разбирает ссылку прокси-протокола в outbound sing-box.
func ParseProxyLink(raw string) (*LinkPreview, error) {
	raw = strings.TrimSpace(raw)
	scheme, _, ok := strings.Cut(raw, "://")
	if !ok {
		return nil, errors.New("ссылка без схемы")
	}
	switch strings.ToLower(scheme) {
	case "vless":
		return parseVLESS(raw)
	case "trojan":
		return parseTrojan(raw)
	case "vmess":
		return parseVMess(raw)
	case "ss":
		return parseShadowsocks(raw)
	default:
		return nil, fmt.Errorf("протокол %q не поддерживается", scheme)
	}
}
```

### 4.3 Разбор `vless://` — соответствие параметров полям sing-box

Ссылка: `vless://<uuid>@<host>:<port>?<params>#<remark>`

| Параметр ссылки | Поле sing-box | Примечание |
|---|---|---|
| `uuid` (userinfo) | `uuid` | обязателен |
| `host:port` | `server`, `server_port` | обязательны |
| `encryption=none` | — | иное значение sing-box не поддерживает (в т.ч. постквантовое `encryption` из Xray 25.x) |
| `security=tls` | `tls.enabled = true` | |
| `security=reality` | `tls.reality.enabled = true` | нужны `pbk`, обычно `sid` |
| `sni` | `tls.server_name` | fallback: `host` → hostname |
| `alpn` | `tls.alpn` (массив) | `h2,http/1.1` |
| `fp` | `tls.utls.fingerprint` | `chrome`, `firefox`, `safari`, `ios`, `random`… Для Reality utls включаем всегда |
| `pbk` | `tls.reality.public_key` | |
| `sid` | `tls.reality.short_id` | |
| `allowInsecure`/`insecure=1` | `tls.insecure = true` | только для отладки |
| `flow=xtls-rprx-vision` | `flow` | поддерживается только Vision |
| `type=tcp` (или пусто) | транспорта нет | «чистый TCP» — то, что нужно по задаче |
| `type=ws` | `transport.type = ws` + `path`, `headers.Host`, `ed` → `max_early_data`, `early_data_header_name` | для Xray-совместимости `Sec-WebSocket-Protocol` |
| `type=grpc` | `transport.type = grpc`, `serviceName` → `service_name` | стандартный gRPC требует build-тег `with_grpc`, встроенный работает без него |
| `type=http`/`h2` | `transport.type = http`, `host`, `path` | |
| `type=httpupgrade` | `transport.type = httpupgrade`, `host`, `path` | |
| `type=quic` | `transport.type = quic` | без доп. шифрования |
| `type=xhttp`/`splithttp`/`kcp` | — | **не поддерживается** sing-box, отклоняем с понятной ошибкой |
| `headerType=http` | — | TCP-обфускация из Xray в sing-box отсутствует |
| `spx` | — | spiderX игнорируется |
| `packetEncoding` | `packet_encoding` | по умолчанию `xudp` |
| `#remark` | имя профиля | |

```go
// backend/link_parse.go (продолжение)

func parseVLESS(raw string) (*LinkPreview, error) {
	u, err := url.Parse(raw)
	if err != nil {
		return nil, fmt.Errorf("некорректный URL: %w", err)
	}
	uuid := u.User.Username()
	if uuid == "" {
		return nil, errors.New("vless: не указан UUID")
	}
	port, err := strconv.Atoi(u.Port())
	if err != nil || port <= 0 || port > 65535 {
		return nil, errors.New("vless: некорректный порт")
	}
	q := u.Query()
	if enc := q.Get("encryption"); enc != "" && enc != "none" {
		return nil, fmt.Errorf("vless: encryption=%q не поддерживается sing-box", enc)
	}

	ob := map[string]any{
		"type":        "vless",
		"tag":         tagProxy, // "proxy"
		"server":      u.Hostname(),
		"server_port": port,
		"uuid":        uuid,
	}
	if flow := q.Get("flow"); flow != "" {
		if flow != "xtls-rprx-vision" {
			return nil, fmt.Errorf("vless: flow=%q не поддерживается (только xtls-rprx-vision)", flow)
		}
		ob["flow"] = flow
	}
	if pe := q.Get("packetEncoding"); pe != "" {
		ob["packet_encoding"] = pe
	}

	security := strings.ToLower(q.Get("security"))
	if security == "" && (q.Get("pbk") != "" || q.Get("sid") != "") {
		security = "reality" // некоторые панели забывают security=reality
	}
	if tlsOpt, err := buildTLS(security, u.Hostname(), q); err != nil {
		return nil, err
	} else if tlsOpt != nil {
		ob["tls"] = tlsOpt
	}

	network := strings.ToLower(q.Get("type"))
	if tr, err := buildTransport(network, q); err != nil {
		return nil, err
	} else if tr != nil {
		ob["transport"] = tr
	}

	obJSON, _ := json.Marshal(ob)
	name := u.Fragment
	if name == "" {
		name = u.Hostname()
	}
	return &LinkPreview{
		Engine: EngineSingbox, Name: name, Protocol: "vless",
		Server: u.Hostname(), Port: port,
		Security: orDefault(security, "none"), Network: orDefault(network, "tcp"),
		Outbound: obJSON, Raw: raw,
	}, nil
}

func buildTLS(security, host string, q url.Values) (map[string]any, error) {
	switch security {
	case "", "none":
		return nil, nil
	case "tls", "reality", "xtls":
	default:
		return nil, fmt.Errorf("security=%q не поддерживается", security)
	}
	sni := firstNonEmpty(q.Get("sni"), q.Get("host"), host)
	tlsOpt := map[string]any{"enabled": true, "server_name": sni}
	if alpn := q.Get("alpn"); alpn != "" {
		tlsOpt["alpn"] = strings.Split(alpn, ",")
	}
	if q.Get("allowInsecure") == "1" || q.Get("insecure") == "1" {
		tlsOpt["insecure"] = true
	}
	if fp := q.Get("fp"); fp != "" {
		tlsOpt["utls"] = map[string]any{"enabled": true, "fingerprint": fp}
	}
	if security == "reality" {
		pbk := q.Get("pbk")
		if pbk == "" {
			return nil, errors.New("reality: отсутствует публичный ключ (pbk)")
		}
		tlsOpt["reality"] = map[string]any{
			"enabled": true, "public_key": pbk, "short_id": q.Get("sid"),
		}
		if _, ok := tlsOpt["utls"]; !ok { // Reality без uTLS работать не будет
			tlsOpt["utls"] = map[string]any{"enabled": true, "fingerprint": "chrome"}
		}
	}
	return tlsOpt, nil
}

func buildTransport(network string, q url.Values) (map[string]any, error) {
	switch network {
	case "", "tcp", "raw", "none":
		return nil, nil // «чистый TCP» — транспорта в конфиге нет
	case "ws":
		path, early := splitEarlyData(q.Get("path"))
		tr := map[string]any{"type": "ws", "path": orDefault(path, "/")}
		if h := firstNonEmpty(q.Get("host"), q.Get("sni")); h != "" {
			tr["headers"] = map[string]any{"Host": h}
		}
		if early == 0 {
			early, _ = strconv.Atoi(q.Get("ed"))
		}
		if early > 0 {
			tr["max_early_data"] = early
			tr["early_data_header_name"] = "Sec-WebSocket-Protocol" // совместимость с Xray
		}
		return tr, nil
	case "grpc":
		return map[string]any{
			"type":         "grpc",
			"service_name": firstNonEmpty(q.Get("serviceName"), q.Get("path")),
		}, nil
	case "http", "h2":
		tr := map[string]any{"type": "http", "path": orDefault(q.Get("path"), "/")}
		if h := q.Get("host"); h != "" {
			tr["host"] = strings.Split(h, ",")
		}
		return tr, nil
	case "httpupgrade":
		tr := map[string]any{"type": "httpupgrade", "path": orDefault(q.Get("path"), "/")}
		if h := q.Get("host"); h != "" {
			tr["host"] = h
		}
		return tr, nil
	case "quic":
		return map[string]any{"type": "quic"}, nil
	default:
		return nil, fmt.Errorf("транспорт %q не поддерживается sing-box (поддержаны tcp, ws, grpc, http, httpupgrade, quic)", network)
	}
}

// splitEarlyData вырезает "?ed=2048" из пути WebSocket.
func splitEarlyData(path string) (string, int) {
	p, qs, ok := strings.Cut(path, "?")
	if !ok {
		return path, 0
	}
	v, _ := url.ParseQuery(qs)
	n, _ := strconv.Atoi(v.Get("ed"))
	return p, n
}
```

```go

```

и предложить добавить пачкой. Реализуется как обёртка `ParseSubscription(text) []*LinkPreview`.

### 4.4 Биндинг для фронта

```go
// backend/app.go
func (a *App) ParseLink(raw string) (*LinkPreview, error) { return ParseProxyLink(raw) }
```

Во фронте `Add-server.tsx`: сначала пробуем старый `parseWdttUrl` (freeturn), если `null` — зовём
`ParseLink` из `wailsjs/go/backend/App`. Если и он вернул ошибку — показываем текст ошибки, а не
безмолвно блокируем кнопку (сейчас именно так и происходит, что для VLESS выглядит как «ссылка
не подходит»).
