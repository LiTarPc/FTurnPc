## 5. Фаза 2. Генератор конфига sing-box

### 5.1 Эталонный конфиг: VLESS + Reality, чистый TCP, обход RU

Это целевой результат генератора (положим в `%AppData%\fturnpc\singbox\config.json`):

```json
{
  "log": { "level": "info", "timestamp": true },
  "dns": {
    "servers": [
      { "type": "udp", "tag": "dns-remote", "server": "1.1.1.1", "detour": "proxy" },
      { "type": "local", "tag": "dns-local" }
    ],
    "rules": [
      { "rule_set": "ru-domains", "action": "route", "server": "dns-local" }
    ],
    "final": "dns-remote",
    "strategy": "ipv4_only"
  },
  "inbounds": [
    {
      "type": "tun",
      "tag": "tun-in",
      "interface_name": "fturn-tun",
      "address": [ "172.19.0.1/30" ],
      "mtu": 1400,
      "auto_route": true,
      "strict_route": true,
      "stack": "mixed",
      "dns_mode": "hijack"
    }
  ],
  "outbounds": [
    {
      "type": "vless",
      "tag": "proxy",
      "server": "example.com",
      "server_port": 443,
      "uuid": "bf000d23-0752-40b4-affe-68f7707a9661",
      "flow": "xtls-rprx-vision",
      "packet_encoding": "xudp",
      "tls": {
        "enabled": true,
        "server_name": "www.microsoft.com",
        "utls": { "enabled": true, "fingerprint": "chrome" },
        "reality": {
          "enabled": true,
          "public_key": "jNXHt1yRo0vDuchQlIP6Z0ZvjT3KtzVI-T4E7RoLJS0",
          "short_id": "0123abcd"
        }

      { "protocol": "dns", "action": "hijack-dns" },

      { "rule_set": [ "geoip-ru", "ru-domains" ], "outbound": "direct" }
    ],
    "rule_set": [
      { "type": "local", "tag": "geoip-ru", "format": "binary", "path": "geoip-ru.srs" },
      { "type": "inline", "tag": "ru-domains", "rules": [ { "domain_suffix": [ ".ru", ".su", ".xn--p1ai" ] } ] }
    ],
    "final": "proxy",
    "auto_detect_interface": true,
    "default_domain_resolver": { "server": "dns-local" }
  },
  "experimental": {
    "cache_file": { "enabled": true, "path": "cache.db" },
    "clash_api": { "external_controller": "127.0.0.1:9095", "secret": "СЛУЧАЙНАЯ_СТРОКА" }
  }
}
```

Что здесь важно и почему (это те места, где обычно всё ломается):

* **`auto_detect_interface: true`** — обязательно. Без него исходящие соединения sing-box сами
  попадут в свой же TUN и получится петля. Это замена вашей текущей ручной логике
  `applyExcludeRoutes` / `AddBypassRoute` для IP TURN-серверов: адрес VLESS-сервера исключать
  маршрутом больше не нужно.
* **`strict_route: true`** — на Windows ставит WFP-фильтр, который и есть защита от DNS-утечек
  через «multihomed DNS resolution». Это замена `windows_dns.go` (NRPT). Учтите: strict_route
  ломает сетевые адаптеры VirtualBox/Hyper-V в отдельных сценариях — стоит вынести в
  «Режим разработчика» переключателем.
* **`dns_mode: "hijack"`** (по умолчанию в 1.14) — sing-box сам прописывает DNS на интерфейсе
  и перехватывает 53-й порт. Отдельная секция `hijack-dns` в правилах оставлена для трафика,
  который приложения отправляют на «свои» DNS напрямую.
* **`final: "proxy"`** — сам по себе killswitch: пока прокси не поднялся, трафик не уходит наружу.
* **`default_domain_resolver: dns-local`** — sing-box 1.12+ требует явно указать, чем резолвить
  домен самого прокси-сервера. Если этого не сделать, будет ошибка старта или циклический резолв.
* **`stack: "mixed"`** — system-стек для TCP (быстрый) + gvisor для UDP (стабильный NAT).
  Официальный бинарь собран с `with_gvisor`, так что доступны все три значения.
* **`route_exclude_address_set` vs правило `rule_set → direct`.** Это два разных обхода:
  правило `{"rule_set":"geoip-ru","outbound":"direct"}` — трафик заходит в TUN, но выходит
  напрямую (просто, никаких маршрутов в системе); `"route_exclude_address_set": ["geoip-ru"]`
  в tun-инбаунде — трафик вообще не заходит в TUN (нужно для локальных серверов/античитов, но это
  тысячи системных маршрутов на старте, как ваш нынешний `netsh -f`). **По умолчанию берите первое**,
  второе — опция «жёсткий обход» в настройках.

### 5.2 Вариации outbound

WebSocket + TLS (обычный «панельный» VLESS):

```json
{
  "type": "vless", "tag": "proxy",
  "server": "cdn.example.com", "server_port": 443,
  "uuid": "…",
  "tls": {
    "enabled": true, "server_name": "cdn.example.com",
    "alpn": [ "h2", "http/1.1" ],
    "utls": { "enabled": true, "fingerprint": "chrome" }
  },
  "transport": {
    "type": "ws", "path": "/ws",
    "headers": { "Host": "cdn.example.com" },
    "max_early_data": 2048,
    "early_data_header_name": "Sec-WebSocket-Protocol"
  }
}
```

Trojan (TCP+TLS) и Shadowsocks — на случай «или подобного TCP-трафика» из задачи:

```json
{ "type": "trojan", "tag": "proxy", "server": "example.com", "server_port": 443,
  "password": "…", "tls": { "enabled": true, "server_name": "example.com",
  "utls": { "enabled": true, "fingerprint": "chrome" } } }
```

```json
{ "type": "shadowsocks", "tag": "proxy", "server": "example.com", "server_port": 8388,
  "method": "2022-blake3-aes-128-gcm", "password": "…" }
```

Мультиплексирование (меньше TCP-хендшейков, заметно быстрее на многих мелких запросах;
не сочетается с `flow: xtls-rprx-vision`):

```json
"multiplex": { "enabled": true, "protocol": "h2mux", "max_streams": 8, "padding": true }
```

### 5.3 Код генератора

```go
// backend/singbox_config.go
package backend

import (
	"crypto/rand"
	"encoding/hex"
	"encoding/json"
	"fmt"
	"os"
	"path/filepath"
)

const (
	tagProxy    = "proxy"
	tagDirect   = "direct"
	singTunName = "fturn-tun"
)

// singboxDir — рабочая директория ядра: config.json, cache.db, логи.
func singboxDir() string {
	dir := filepath.Join(configDir(), "singbox")
	_ = os.MkdirAll(dir, 0o755)
	return dir
}

func newSecret() string {
	b := make([]byte, 16)
	_, _ = rand.Read(b)
	return hex.EncodeToString(b)
}

// BuildSingboxConfig собирает конфиг sing-box из профиля и runtime-параметров UI.
func BuildSingboxConfig(p *ProfileData, cp ConnectParams, secret string) ([]byte, error) {
	if len(p.Outbound) == 0 {
		return nil, fmt.Errorf("профиль %q: пустой outbound", p.Name)
	}
	var outbound map[string]any
	if err := json.Unmarshal(p.Outbound, &outbound); err != nil {
		return nil, fmt.Errorf("профиль %q: некорректный outbound: %w", p.Name, err)
	}
	outbound["tag"] = tagProxy
	outbound["domain_resolver"] = "dns-local" // резолвим адрес сервера системным DNS

	opt := p.Sing
	mtu := firstPositive(cp.MTU, opt.MTU, 1400)
	stack := orDefault(opt.Stack, "mixed")
	strict := boolOr(opt.StrictRoute, true)
	sniff := boolOr(opt.Sniff, true)
	bypassLAN := boolOr(opt.BypassLAN, true)
	bypassRu := cp.BypassRu || opt.BypassRu
	clashPort := firstPositive(opt.ClashPort, 9095)

	tun := map[string]any{
		"type":           "tun",
		"tag":            "tun-in",
		"interface_name": singTunName,
		"address":        []string{"172.19.0.1/30"},
		"mtu":            mtu,
		"auto_route":     true,
		"strict_route":   strict,
		"stack":          stack,
		"dns_mode":       "hijack",
	}
	if opt.IPv6 {
		tun["address"] = []string{"172.19.0.1/30", "fdfe:dcba:9876::1/126"}
	}

	var rules []map[string]any
	if sniff {
		rules = append(rules, map[string]any{"action": "sniff", "timeout": "300ms"})
	}
	rules = append(rules, map[string]any{"protocol": "dns", "action": "hijack-dns"})
	if bypassLAN {
		rules = append(rules, map[string]any{"ip_is_private": true, "outbound": tagDirect})
	}

	var ruleSets []map[string]any
	var dnsRules []map[string]any
	if bypassRu {
		if srs := findGeoIPRuSRS(); srs != "" {
			ruleSets = append(ruleSets, map[string]any{
				"type": "local", "tag": "geoip-ru", "format": "binary", "path": srs,
			})
		} else if cidrs := loadGeoIPRuCIDRs(); len(cidrs) > 0 { // fallback на ваш geoip-ru.txt
			ruleSets = append(ruleSets, map[string]any{
				"type": "inline", "tag": "geoip-ru",
				"rules": []map[string]any{{"ip_cidr": cidrs}},
			})
		}
		ruleSets = append(ruleSets, map[string]any{
			"type": "inline", "tag": "ru-domains",
			"rules": []map[string]any{{"domain_suffix": []string{".ru", ".su", ".xn--p1ai"}}},
		})
		rules = append(rules, map[string]any{
			"rule_set": []string{"geoip-ru", "ru-domains"}, "outbound": tagDirect,
		})
		dnsRules = append(dnsRules, map[string]any{
			"rule_set": "ru-domains", "action": "route", "server": "dns-local",
		})
	}

	cfg := map[string]any{
		"log": map[string]any{"level": "info", "timestamp": true},
		"dns": map[string]any{
			"servers": []map[string]any{
				{"type": "udp", "tag": "dns-remote",
					"server": orDefault(opt.DNSRemote, "1.1.1.1"), "detour": tagProxy},
				{"type": "local", "tag": "dns-local"},
			},
			"rules":    dnsRules,
			"final":    "dns-remote",
			"strategy": ifThen(opt.IPv6, "prefer_ipv4", "ipv4_only"),
		},
		"inbounds":  []map[string]any{tun},
		"outbounds": []any{outbound, map[string]any{"type": "direct", "tag": tagDirect}},
		"route": map[string]any{
			"rules":                   rules,
			"rule_set":                ruleSets,
			"final":                   tagProxy,
			"auto_detect_interface":   true,
			"default_domain_resolver": map[string]any{"server": "dns-local"},
		},
		"experimental": map[string]any{
			"cache_file": map[string]any{"enabled": true, "path": "cache.db"},
			"clash_api": map[string]any{
				"external_controller": fmt.Sprintf("127.0.0.1:%d", clashPort),
				"secret":              secret,
			},
		},
	}
	return json.MarshalIndent(cfg, "", "  ")
}

// findGeoIPRuSRS ищет geoip-ru.srs рядом с exe и в assets/freeturn (как getFreeturnPath).
func findGeoIPRuSRS() string {
	exe, _ := os.Executable()
	dir := filepath.Dir(exe)
	for _, p := range []string{
		filepath.Join(dir, "geoip-ru.srs"),
		filepath.Join(dir, "assets", "freeturn", "geoip-ru.srs"),
		filepath.Join(configDir(), "geoip-ru.srs"),
	} {
		if _, err := os.Stat(p); err == nil {
			return p
		}
	}
	return ""
}
```

Функции-хелперы (`orDefault`, `firstPositive`, `boolOr`, `ifThen`, `firstNonEmpty`) — 10 строк в
`backend/util.go`.

### 5.4 Валидация до запуска

Не запускайте ядро «на удачу» — у sing-box есть встроенная проверка:

```bash
sing-box check -c config.json      # схема + семантика; код возврата 0/1
sing-box format -c config.json -w  # переформатировать (удобно для «показать конфиг» в UI)
sing-box version                   # версия + список build-тегов
```

В Go это 15 строк, зато все ошибки конфига становятся понятным текстом в окне логов:

```go
func singboxCheck(exePath, cfgPath string) error {
	cmd := exec.Command(exePath, "check", "-c", cfgPath)
	hideWindow(cmd)
	out, err := cmd.CombinedOutput()
	if err != nil {
		return fmt.Errorf("конфиг не прошёл проверку: %s", strings.TrimSpace(string(out)))
	}
	return nil
}
```

### 5.5 Полезные необязательные блоки

| Задача | Что добавить |
|---|---|
| Убить QUIC (браузеры уходят на UDP/443 и тормозят через xudp) | правило `{ "network": "udp", "port": 443, "action": "reject" }` |
| Обход по процессам (лончеры, банк-клиенты) | `route.find_process: true` + `{ "process_name": ["steam.exe"], "outbound": "direct" }` |
| Реклама/трекеры в блок | `{ "rule_set": "geosite-ads", "action": "reject" }` + remote rule-set с `update_interval` |
| Несколько серверов + автовыбор | `{ "type": "urltest", "tag": "auto", "outbounds": ["s1","s2"], "url": "https://cp.cloudflare.com", "interval": "3m" }`, `final: "auto"` |
| Ручное переключение из UI без перезапуска | `{ "type": "selector", "tag": "select", "outbounds": [...] }` + Clash API `PUT /proxies/select` |
| Лог в файл, а не в stdout | `log.output: "singbox.log"` (но тогда парсинг stdout не работает — оставьте stdout) |
