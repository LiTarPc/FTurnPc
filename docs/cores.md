# Замена ядер и откат

[Все разделы документации](README.md)

## Два разных ядра

FreeTurn устанавливает транспорт к серверу, sing-box создаёт TUN и обрабатывает VPN/proxy-протокол. Кнопка «Заменить ядро» предназначена только для FreeTurn: не выбирайте там `sing-box.exe`, серверный бинарник или installer.

Ручной выбор проверяет формат исполняемого файла, но не доказывает правильность ядра, архитектуры или протокола. Используйте доверенный Windows amd64/x64 клиент. Скачанный `.exe` будет запускаться с правами приложения.

## Подготовка

1. Проверьте [совместимость](compatibility.md), включая серверное ядро.
2. Сохраните рабочие FreeTurn `.exe`, `sing-box.exe` и имеющийся `core_version.txt` в отдельную папку вне каталога установки.
3. Сохраните профили, запишите версии, источники и хеши новых файлов.
4. Отключите туннель. При замене через Проводник полностью закройте FTurnPc, включая трей.
5. Меняйте одно ядро за раз.

Временный `.old`, создаваемый встроенной заменой, удаляется после успеха. Это защита от ошибки файловой операции, не постоянная резервная копия.

## Замена FreeTurn через UI

1. Скачайте клиент Windows x64 из [релизов форка](https://github.com/LiTarPc/fturn-core/releases) или другого доверенного источника после проверки совместимости.
2. Если скачан ZIP, распакуйте его: ручной выбор ожидает `.exe`, не архив.
3. Откройте настройки → «Ядро FreeTurn» → «Заменить ядро».
4. Выберите клиентский файл и дождитесь результата.
5. Проверьте версию и подключение, откройте сайты и убедитесь, что растут счётчики.

Приложение копирует содержимое выбранного файла в текущее место установки ядра; исходное имя выбранного файла сохранять не нужно. На активной сессии оно пытается остановить и восстановить соединение, но предпочтительнее отключиться заранее.

Версия в виде сборки/хеша или невозможность её определения не обязательно означают повреждённый файл. Стороннее ядро может не поддерживать способ получения версии, используемый UI. Запишите его релиз и SHA256 самостоятельно.

## Как выбирается FreeTurn

Имена проверяются по порядку:

1. `freeturnclient.exe`
2. `client-windows-amd64.exe`
3. `client.exe`
4. Те же имена без `.exe`

Для **каждого имени** проверяются `<папка FTurnPc>\assets\freeturn\`, папка рядом с `.exe` приложения, затем `PATH`. Только потом проверяется следующее имя.

Старый `freeturnclient.exe` может иметь приоритет над новым `client-windows-amd64.exe`. Файл с первым именем в `PATH` может быть выбран раньше локального со вторым именем. Не оставляйте конкурирующие копии без необходимости.

Если файла нет, ожидается `freeturnclient.exe` рядом с FTurnPc. Встроенная замена пишет в выбранный поиском путь: если найдено ядро в `PATH`, операция может затронуть его. Предпочитайте отдельное ядро рядом с приложением и проверяйте путь до замены.

При ручной замене через Проводник положите проверенный клиент как `freeturnclient.exe` рядом с FTurnPc, сохранив старый файл и проверив отсутствие приоритетной копии в `assets\freeturn`. Нельзя просто переименовать произвольный proxy-клиент: ожидается FreeTurn CLI.

## Замена sing-box

1. Полностью закройте FTurnPc и сохраните старый `sing-box.exe`.
2. Распакуйте Windows amd64/x64 сборку, проверенную с данной версией FTurnPc.
3. Замените выбранный приложением `sing-box.exe`. Проще использовать файл рядом с FTurnPc.
4. Проверьте версию и запустите приложение.
5. Подключитесь: приложение автоматически проверит сгенерированную конфигурацию через `sing-box check`.

Порядок поиска:

1. `<папка FTurnPc>\sing-box.exe`
2. `<папка FTurnPc>\assets\singbox\sing-box.exe`
3. `%AppData%\FTurnPc-singbox\core\sing-box.exe`
4. `sing-box` в `PATH`

Пример проверки в PowerShell; замените путь своим:

```powershell
& 'C:\Apps\FTurnPc\sing-box.exe' version
```

Для конкретной конфигурации:

```powershell
& 'C:\Apps\FTurnPc\sing-box.exe' check -c 'C:\Temp\config.json'
```

Проверка не заменяет тест соединения. Не публикуйте `config.json`: там могут быть секреты. У закреплённого FreeTurn-форка есть `-version`, но у произвольного upstream-бинарника этот флаг не гарантирован.

## Откат

1. Отключите туннель и полностью закройте FTurnPc.
2. Восстановите прежний исполняемый файл из своей копии в выбранный приложением путь.
3. Для FreeTurn восстановите `core_version.txt` из той же копии, если он был. Не оставляйте метку версии от заменённого ядра.
4. Проверьте профиль, версию и соединение после запуска.
5. Если менялся серверный протокол, согласуйте откат с администратором: локального восстановления может быть недостаточно.

Не удаляйте TUN-адаптеры и маршруты массово ради отката. Сначала используйте штатное отключение и логи.
