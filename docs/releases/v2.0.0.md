# FTurnPc 2.0.0 — Windows sing-box

Основная ветка `main` перешла на sing-box + FreeTurn. Прежняя реализация подключения через WG сохранена в ветке [wg](https://github.com/LiTarPc/FTurnPc/tree/wg). Истории обеих реализаций сохранены.

## Что входит в выпуск

- Windows x64 NSIS installer с sing-box 1.14.0 и FreeTurn из `LiTarPc/fturn-core`, ревизия `58d4f175d245c5773786e19ace454216c625f92f`, маркировка версии 4.1.3.
- TUN sing-box, TCP/UDP relay FreeTurn, поддержка профилей WireGuard и proxy URI/JSON.
- Исправления готовности транспорта, физических маршрутов к peer/TURN и конфликтов TUN-адаптера.
- 64-битные счётчики трафика Windows с baseline текущей сессии.
- Обход приложений и RU-адресов, обновление RU CIDR, настройка DNS sing-box и MTU.
- Автозапуск через Планировщик заданий Windows и ожидание сети при стартовом автоподключении.
- [Документация](https://github.com/LiTarPc/FTurnPc/tree/main/docs): управление, обновления, замена ядер, откат и диагностика.

## Установка и переход с WG-версии

1. Сохраните профили, настройки и рабочие ядра.
2. Отключите туннель и полностью завершите старое приложение, включая трей.
3. Установите Windows x64 installer из этого релиза.
4. Проверьте импортированные параметры и подключение. Настройки старого интерфейса не следует считать полностью перенесёнными без проверки.
5. Если изменился путь приложения, заново включите автозапуск.

Для прежнего поведения используйте ветку `wg` и старую рабочую сборку. Поддержка WG-профилей в sing-box не равна сохранению старого WG-движка.

## Ограничения

- Выпуск предназначен для Windows x64; Linux/macOS пакеты не выпускаются.
- Новый upstream `provider direct` и TCP `bond` пока не поддержаны интерфейсом.
- Новые upstream `freeturn://` могут требовать ручного восстановления ссылки звонка и числовых параметров.
- Не заменяйте клиент на новый upstream без проверки серверного ACK-протокола Client ID.
- Отдельного OS-level kill switch нет.

Подробнее: [совместимость](https://github.com/LiTarPc/FTurnPc/blob/main/docs/compatibility.md).

Рядом с installer опубликован SHA256. Сверьте хеш скачанного файла с приложенным `.sha256.txt`. Windows-сборка запускает backend-тесты и проверку схемы конфигураций на упаковываемом sing-box; это не заменяет проверку подключения к вашему серверу.
