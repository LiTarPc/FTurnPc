# FTurnPc 2.0.1 — светлый бордовый интерфейс

## Что изменилось

- Новая светлая тема: тёплый молочный фон, мягкие бежевые поверхности и тёмный графитово-сливовый текст.
- Бордовые кнопки подключения, активные переключатели, выбранные серверы, фильтры журнала и DNS.
- Кремовый текст и иконки на бордовых элементах; отдельные цвета наведения и нажатия.
- Единое оформление настроек, профилей, обхода приложений, обновления ядра и уведомлений.
- Мягкие скругления, тонкие разделители и лёгкие тени.
- Системный шрифт Segoe UI для интерфейса и моноширинный шрифт для журнала.
- Видимый фокус при работе с клавиатуры, доступные подписи переключателей и поддержка уменьшения анимации.
- В тёмной теме также используются бордовые акценты.

## Установка

1. Отключите туннель и полностью завершите приложение, включая значок в трее.
2. Запустите `FTurnPc-v2.0.1-windows-amd64-installer.exe`.
3. Если сохранена тёмная тема, включите светлую кнопкой с солнцем/луной внизу боковой панели.

Выпуск предназначен для Windows x64. Комплект ядер соответствует v2.0.0: sing-box 1.14.0 и FreeTurn 4.1.3 (ревизия `58d4f175d245c5773786e19ace454216c625f92f`). Подробности совместимости и обновления: [документация](https://github.com/LiTarPc/FTurnPc/tree/main/docs).

Рядом с установщиком опубликован файл SHA256. Сборка релиза проверяет backend и схемы конфигураций sing-box; внешний вид проверен при размерах окна 430×670 и 400×450.
