# Обновление приложения и данных

[Все разделы документации](README.md)

## Что именно обновляется

| Компонент | Способ | Источник |
| --- | --- | --- |
| FTurnPc, UI и backend | Новый Windows installer | [Релизы FTurnPc](https://github.com/LiTarPc/FTurnPc/releases) |
| FreeTurn | «Проверить обновление» → «Обновить ядро» | [LiTarPc/fturn-core](https://github.com/LiTarPc/fturn-core/releases), включая preview |
| sing-box | Новый пакет FTurnPc или ручная замена | [Релизы sing-box](https://github.com/SagerNet/sing-box/releases) |
| RU CIDR | «Обновить RU CIDR» в окне «Обход» | IPdeny, компиляция через sing-box |

Кнопка «Обновить ядро» обновляет только FreeTurn, не UI, sing-box или сервер на VPS.

## Обновление FTurnPc

1. Сохраните копию `%AppData%\FTurnPc-singbox` и рабочих ядер. Запишите настройки UI: они частично хранятся в WebView.
2. Отключите VPN и полностью закройте приложение, включая трей.
3. Скачайте [Sing-box Fix Preview](https://github.com/LiTarPc/FTurnPc/releases/tag/singbox-fix-latest) или выбранный релиз. Сверьте SHA256 с опубликованным значением, если оно приложено.
4. Установите в нужную папку. Установщик может заменить ядра, в том числе установленные вручную.
5. Проверьте профиль, обход, версии и подключение.

Не удаляйте пользовательскую папку ради обычного обновления. При смене каталога заново настройте автозапуск.

Пример проверки скачанного файла в PowerShell; подставьте свой путь:

```powershell
Get-FileHash -LiteralPath 'C:\Downloads\FTurnPc-installer.exe' -Algorithm SHA256
```

Вычисленный хеш нужно сравнить с доверенным опубликованным значением; сам по себе он не подтверждает происхождение файла.

## Обновление FreeTurn

1. Предпочтительно отключите туннель заранее.
2. Откройте настройки → «Ядро FreeTurn (freeturnclient)».
3. Нажмите «Проверить обновление».
4. Если доступна версия, нажмите «Обновить ядро» и дождитесь завершения.
5. Проверьте версию и подключение.

«Автопроверка обновлений ядра» только проверяет наличие версии при старте и показывает уведомление; она не устанавливает файл автоматически.

Обновлятор использует релизы `LiTarPc/fturn-core`, включая preview; отдельного переключателя stable/preview нет. Ошибка связи с GitHub не доказывает актуальность ядра. Повторите проверку или используйте [ручную замену](cores.md).

Если сессия активна, backend останавливает её перед заменой и после успеха пытается запустить с прежними параметрами. Соединение прерывается. Успешная установка не гарантирует успешного переподключения; после ошибки при необходимости подключитесь вручную.

## Обновление sing-box

Отдельной кнопки автообновления нет. Используйте согласованную сборку FTurnPc либо [ручную замену](cores.md#замена-sing-box).

Эта ветка проверяет минимальную версию `1.14.0`, сборка закрепляет `1.14.0`. Это нижняя граница проверки, не обещание совместимости с любой будущей версией: новая схема конфигурации может потребовать изменений backend.

## Обновление российских сетей

1. Отключите соединение.
2. Откройте «Обход» → `RU CIDR` → «Обновить RU CIDR».
3. Дождитесь обновления источника, количества сетей и даты.
4. Включите обход RU-адресов, если нужен, сохраните настройки и подключитесь снова.

Приложение скачивает IPv4 CIDR из [IPdeny RU aggregated](https://www.ipdeny.com/ipblocks/data/aggregated/ru-aggregated.zone), проверяет список и компилирует `geoip-ru.srs` установленным sing-box. Файлы сохраняются в `%AppData%\FTurnPc-singbox`. Правила применяются при следующем подключении.

## Если после обновления стало хуже

Не меняйте сразу другие компоненты. Сохраните лог и восстановите последний изменённый компонент: [откат ядер](cores.md#откат). Для приложения используйте сохранённый installer предыдущей рабочей сборки; он также может заменить ядра.
