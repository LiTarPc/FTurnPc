# Установка и управление

[Все разделы документации](README.md)

## Первый запуск

1. Скачайте Windows x64 installer из [Sing-box Fix Preview](https://github.com/LiTarPc/FTurnPc/releases/tag/singbox-fix-latest). Это rolling preview: состав пакета меняется при новых сборках ветки.
2. Установите приложение и запустите FTurnPc с правами администратора. Они нужны для TUN и маршрутов Windows.
3. Добавьте профиль, полученный от администратора сервера.
4. Выберите профиль и нажмите кнопку подключения.
5. Проверьте сайты и приложения; при ошибке откройте страницу логов.

Установщик Windows x64 включает FreeTurn и sing-box. Для запуска без установщика внешние файлы нужно разместить самостоятельно: [расположение ядер](cores.md).

## Профили

Добавляйте `freeturn://` через окно добавления сервера. Также распознаются `wdtt://`, JSON профиля и WireGuard `.conf`. После импорта проверьте параметры: новые ссылки upstream переносятся не полностью — [ограничения импорта](compatibility.md#импорт-ссылок).

В редакторе можно задать мощность и `Streams/cred`. «Режим разработчика» открывает поля:

| Поле | Назначение |
| --- | --- |
| `VK Call (Links)` | Ссылка звонка для TURN-реквизитов |
| `Peer (Address)` | Адрес и порт FreeTurn-сервера |
| `Transport` | Транспорт до TURN: `tcp` или `udp` |
| `Obf Profile` / `Obf Key` | Обфускация, соответствующая серверу |
| `Client ID` | Идентификатор для авторизации |
| `WG Config` | WG-конфигурация, преобразуемая в sing-box endpoint |
| `SB Config / URI` | sing-box JSON или proxy URI |
| `Provider` | Сохраняется, но сейчас не передаётся CLI ядра |

Режим разработчика не добавляет поддержку `provider direct` или `bond`. Имя профиля не должно содержать точку, `/` или `\`. Сохраняйте копию перед редактированием. Без `wg` или `sb` профиль не задаёт VPN/proxy-протокол: одних peer и ключа недостаточно.

## Подключение и отключение

Приложение проверяет конфигурацию sing-box, запускает FreeTurn, обнаруживает TURN-адреса и создаёт маршруты. После готовности транспорта запускается TUN sing-box.

При активном подключении кнопка отключает туннель. После ручного отключения есть короткая пауза перед повторным подключением. Не запускайте вторую копию FTurnPc или отдельный FreeTurn на `127.0.0.1:9000` одновременно.

Локальный порт `127.0.0.1:9000` используется автоматически. Не подменяйте им `Peer`: поле должно указывать на ваш сервер.

## Обход, DNS и MTU

В окне «Обход» можно включить обход RU-адресов, добавить процесс (`steam.exe`) или путь к приложению, задать DNS sing-box, изменить MTU и обновить RU CIDR.

Обход направляет трафик напрямую, вне VPN. Учитывайте дочерние процессы: правило для одного `.exe` не охватывает автоматически все программы пакета. Правила применяются при следующем подключении. Это split tunneling sing-box, не исключение WFP/WinDivert. Независимого OS-level kill switch сейчас нет.

DNS относится к трафику sing-box, не к API звонков и captcha FreeTurn. Поддерживаются IP и `udp://`, `tls://`, `https://`. Пустое поле оставляет DNS WG-профиля либо `1.1.1.1`.

MTU принимает целые значения от 576 до 1500; стандартная настройка UI — 1300. Для WG отдельно рассчитывается MTU TUN, поэтому значение UI не обязательно равно MTU Windows-интерфейса. Во время подключения MTU менять нельзя. Проверяйте результат после переподключения, меняя один параметр за раз.

## Автозапуск и трей

Трей, запуск вместе с Windows и автоподключение включаются отдельно. Автозапуск использует Планировщик заданий с повышенными правами; для регистрации нужны соответствующие права.

Перед переносом выключите автозапуск, затем включите его из новой папки: задача привязана к пути `.exe`. Перед заменой файлов полностью завершайте приложение, включая трей. Закрытие окна и завершение процесса — разные действия.

## Пользовательские данные

Файлы находятся в `%AppData%\FTurnPc-singbox`:

| Путь | Содержимое |
| --- | --- |
| `profiles\*.json` | Профили с секретами |
| `bypass-apps.json` | Обход приложений |
| `logs\*.log` | Логи сессий |
| `geoip-ru.txt`, `geoip-ru.srs` | RU-список |
| `singbox\` | Генерируемые конфигурации |

Часть настроек UI хранится в `localStorage` WebView. Копирование только `profiles` не является полным переносом настроек. Дополнительно запишите DNS, MTU, обход и автоподключение.

Не публикуйте эту папку целиком: удалите ключи, UUID, пароли, Client ID и ссылки звонков перед отправкой в GitHub Issues.
